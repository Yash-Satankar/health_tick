# Asset attribution

## Reference crops
All other PNG files in this folder were cropped from the HealthTick reference video during the planning session
(see `seed/asset-manifest.json` for each crop's source timestamp and quality rating).

## Microsoft Fluent Emoji (MIT License)
The following files are the **3D PNG** renders from [microsoft/fluentui-emoji](https://github.com/microsoft/fluentui-emoji),
downloaded on 2026-10-13 from the `main` branch (commit `1ffb34c752ecf5d402f04cfb4b392c77f57c54bc`).
None of these emoji have skin-tone variants, so each one comes from `assets/<Name>/3D/<name>_3d.png`.
They are saved under the file names that `asset-manifest.json` expects. They are unmodified; each is 256×256.
