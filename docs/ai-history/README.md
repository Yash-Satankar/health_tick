# AI conversation history

This folder holds **raw conversation exports**, which the user adds manually:

- The prior **Claude chat planning session** that produced the requirements, `SPEC.md`, the database schema, the API
  contract, the content transcription (`journey_content.yaml`) and the asset crops.
- The **Claude Code implementation session(s)**, exported with `/export` or by copying the session file.

These files are kept verbatim as evidence for the assessment and are not edited.
`docs/AI_WORKLOG.md` is the curated, append-only summary of the implementation work.
